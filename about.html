About this project

I'm Faith, a software engineering student, and this is a small side project built with plain HTML and CSS — no frameworks, no JavaScript. Partly to have somewhere to keep my recipes properly written down, and partly just to practice building a real multi-page site from scratch.

The category filter on the recipes page and the mobile menu are both done with CSS only, using checkbox and radio input tricks instead of any scripting.

Still adding recipes as I go — Moi Moi, Suya, and Zobo are next on the list.
